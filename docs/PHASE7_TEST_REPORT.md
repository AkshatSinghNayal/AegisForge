The other five journeys passed separately; this is **six distinct passing real-backend tests**, not a claim that the intermediate six-test invocation was fully green.

Mock completion is deliberately **partial / mock / report failed / effective gate fail**. Its simulated manifest is not real security evidence, and it creates no persisted PolicyEvaluation or Report ID. Cancellation revokes the database fence immediately; an already-running network-free mock computation may finish within its bounded worker limit, but its result cannot advance the cancelled scan. Real runner stop/egress revocation and execution-time DNS enforcement must be implemented with the future real adapter before any target traffic is enabled. Redis/database outages can delay reconciliation, but cannot yield a passing result; persisted deadlines are applied on recovery. Lists retain the Phase 6 200-record cap.
